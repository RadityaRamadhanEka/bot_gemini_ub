Buat draft produksi untuk Episode 4 dari seri “Kulik Data With Gemini”. Ikuti gaya dan struktur draft episode sebelumnya: praktis, ramah untuk pemula, berbahasa Indonesia sehari-hari, dan relevan untuk mahasiswa UB.

BRIEF EPISODE
- Judul: “SQL itu seperti meminta petugas mencari pesanan tertentu di buku kas”
- Format: Instagram Reel vertikal 9:16, durasi 30–45 detik
- Pilar: Study Hack
- Audiens: Mahasiswa dan pemula yang belum belajar SQL
- Analogi: Kita meminta petugas kantin mencari transaksi dengan kriteria tertentu di buku kas. Tegaskan bahwa analogi ini hanya penyederhanaan.
- Pesan utama: SQL membantu memilih data dari tabel berdasarkan kriteria yang kita tentukan.
- Demo Gemini: Mengajarkan query dasar untuk menampilkan transaksi menu “Nasi Ayam” dari tabel `transaksi`.
- Data demo harus sintetis/fiktif, bukan data pribadi atau transaksi nyata.
- CTA yang disarankan: “Coba tulis query untuk menu favoritmu!”

PROMPT GEMINI YANG HARUS DIMASUKKAN DALAM DRAFT
“Ajari saya query SQL dasar untuk menampilkan transaksi menu 'Nasi Ayam' dari tabel transaksi. Jelaskan fungsi SELECT, FROM, dan WHERE dengan bahasa sehari-hari. Gunakan hanya klausa tersebut, jangan menambahkan klausa atau fungsi SQL lain. Berikan satu latihan serupa tanpa langsung memberi jawabannya. Jika struktur tabel belum disebutkan, nyatakan asumsi yang digunakan.”

SUSUN DRAFT DENGAN BAGIAN BERIKUT
1. Tujuan konten dan satu pesan utama.
2. Hook pembuka yang menarik untuk 0–3 detik.
3. Rencana adegan dalam tabel berisi waktu, framing/aksi, teks overlay persis, narasi persis, dan aksi layar/demo.
4. Demo Gemini: prompt lengkap siap ditempel dan contoh hasil ilustratif yang sesuai dengan prompt.
5. Naskah lisan lengkap yang durasinya realistis untuk Reel 30–45 detik.
6. Caption siap unggah, CTA, hashtag #GeminiAcademy dan #GeminiAcademyUB, serta mention @geminiacademybyrefo dan tag @REFO Indonesia.
7. Checklist produksi singkat, termasuk keterbacaan teks, safe area, dan penggunaan data fiktif.

BATASAN DAN PENGECEKAN
- Pastikan durasi adegan jika dijumlahkan sesuai dengan durasi total Reel.
- Gunakan satu contoh query yang valid, misalnya:
  SELECT * FROM transaksi WHERE menu = 'Nasi Ayam';
- Jelaskan bahwa `SELECT *` memilih semua kolom; `FROM transaksi` menunjukkan tabel sumber; dan `WHERE menu = 'Nasi Ayam'` menyaring baris sesuai kriteria.
- Jangan memakai klausa SQL selain SELECT, FROM, dan WHERE pada contoh query.
- Jangan mengarang hasil query atau mengklaim bahwa data tertentu benar-benar ada. Jika memakai contoh hasil, beri label sebagai ilustrasi dari data sintetis.
- Jangan menyiratkan bahwa Gemini menjalankan query atau memeriksa database; Gemini hanya membantu menjelaskan dan menyusun contoh.
- Hindari klaim berlebihan. Buat dialog ringkas, natural, dan cukup singkat untuk dibawakan dalam durasi yang ditentukan.

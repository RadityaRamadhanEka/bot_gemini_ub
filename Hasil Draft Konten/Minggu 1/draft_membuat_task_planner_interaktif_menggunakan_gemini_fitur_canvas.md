### Draf Produksi Carousel (6 Slide)

#### Slide 1: Cover
* **Tujuan:** Menarik atensi mahasiswa UB yang sering keteteran tugas kuliah dengan solusi praktis tanpa perlu keahlian *coding*.
* **Teks Layar (Siap Tempel):**
  * *Headline:* Sering Lupa Deadline Tugas Kuliah?
  * *Sub-headline:* Bikin Task Planner Interaktif Sendiri Pakai Gemini Canvas!
  * *Micro-copy:* 100% Gratis • Berjalan Lokal di Laptop • Tanpa Perlu Bisa Koding
* **Arahan Visual/Layout:**
  * Background bersih (tema warna Google / Gemini: putih, biru lembut, aksen ungu).
  * Ilustrasi atau foto ekspresif mahasiswa sedang menatap laptop dengan kalender/catatan tugas yang menumpuk.
  * Tampilkan ikon Gemini bersanding dengan *mockup* antarmuka task planner mini di sudut slide.

---

#### Slide 2: Masalah & Solusi (Fitur Canvas)
* **Tujuan:** Mengenalkan fitur Canvas Gemini sebagai ruang kerja interaktif untuk membuat dokumen/kode siap pakai.
* **Teks Layar (Siap Tempel):**
  * *Header:* Kenapa Pakai Fitur Canvas di Gemini?
  * *Poin 1:* **Tampilan Dua Panel:** Obrolan prompt di kiri, kode & hasil *preview* di kanan.
  * *Poin 2:* **Langsung Edit di Tempat:** Bisa minta Gemini revisi tombol atau tampilan secara instan.
  * *Poin 3:* **Bisa Disimpan Offline:** Menghasilkan file HTML yang bisa dibuka langsung di browser laptop kapan saja.
* **Arahan Visual/Layout:**
  * Tangkapan layar antarmuka Gemini saat fitur Canvas terbuka (tunjukkan panel kiri untuk prompt, panel kanan untuk kode/dokumen).
  * Berikan panah penunjuk elegan ke arah panel Canvas di sisi kanan.

---

#### Slide 3: Prompt Siap Pakai
* **Tujuan:** Memberikan prompt terstruktur yang bisa disalin langsung oleh mahasiswa.
* **Teks Layar (Siap Tempel):**
  * *Header:* Copy Prompt Ini ke Gemini Canvas
  * *Box Prompt:*
    ```text
    Buka mode Canvas. Buatkan satu file HTML lengkap berisi aplikasi 'UB Student Task Planner' dengan CSS & JavaScript internal.
    Fitur wajib:
    1. Input: Nama Mata Kuliah, Judul Tugas, Deadline, dan Prioritas (Tinggi/Sedang/Rendah).
    2. Checkbox penanda tugas selesai.
    3. Penyimpanan otomatis menggunakan localStorage browser (data tidak hilang saat di-refresh).
    4. Tampilan antarmuka bersih, modern, dan rapi.
    ```
* **Arahan Visual/Layout:**
  * Teks prompt diletakkan di dalam kontainer bergaya *code box* atau *card* dengan ikon salin (*copy icon*).
  * Tipografi monospace yang bersih dan kontras tinggi agar nyaman dibaca di layar HP.

---

#### Slide 4: Demo Interaksi di Layar Gemini
* **Tujuan:** Memperlihatkan proses eksekusi kode di Canvas secara nyata dan transparan.
* **Teks Layar (Siap Tempel):**
  * *Header:* Lihat Hasilnya Langsung Muncul di Kanan!
  * *Step 1:* Gemini menyusun kode HTML/JS di panel Canvas.
  * *Step 2:* Klik tombol **Preview** untuk mencoba aplikasi langsung di dalam Gemini.
  * *Step 3:* Mau tambah fitur filter mata kuliah? Cukup ketik revisi di panel chat.
* **Arahan Visual/Layout:**
  * *Mockup* UI Gemini: Tampilkan teks prompt di panel kiri, dan di panel kanan terlihat cuplikan kode serta tombol *run/preview*.
  * *(Catatan Produksi: Gunakan tangkapan layar asli interaksi Gemini saat rekaman/produksi visual; jangan gunakan data sensitif).*

---

#### Slide 5: Cara Simpan & Pakai di Laptop
* **Tujuan:** Panduan teknis sederhana agar file bisa dipakai sehari-hari tanpa internet.
* **Teks Layar (Siap Tempel):**
  * *Header:* Cara Simpan ke Laptop (1 Menit Jadi)
  * *Langkah 1:* Klik ikon salin kode (*copy code*) di pojok kanan atas Canvas.
  * *Langkah 2:* Buka aplikasi Notepad / TextEdit, lalu *Paste* (tempel) kodenya.
  * *Langkah 3:* Simpan file dengan nama `planner_tugas.html` (pastikan ekstensi `.html`).
  * *Langkah 4:* Klik dua kali file tersebut. Planner tugas siap dipakai offline di browser favoritmu!
* **Arahan Visual/Layout:**
  * Diagram alur langkah 1-4 dengan ikon sederhana: Salin -> Buka Notepad -> Simpan sebagai .html -> Buka di Google Chrome.

---

#### Slide 6: Rangkuman & CTA
* **Tujuan:** Menyimpulkan manfaat Gemini untuk produktivitas kampus dan mengajak interaksi.
* **Teks Layar (Siap Tempel):**
  * *Header:* Kuliah Lebih Rapi, Tugas Nggak Ada yang Kelewat
  * *Highlight:* Gemini bukan cuma buat cari jawaban, tapi bisa jadi asisten produktivitas kamu sehari-hari!
  * *Call to Action:*
    * Mau prompt lengkapnya? Tulis **"PLANNER"** di kolom komentar!
    * Simpan postingan ini biar nggak hilang pas butuh bikin planner!
* **Arahan Visual/Layout:**
  * Foto Raditya dengan pose mengajak (*friendly & engaging*).
  * Elemen visual grafis "Save & Share".
  * Logo Gemini Academy dan penempatan tag @REFO Indonesia yang rapi di pojok bawah.

### Checklist Desain & Keamanan Data (Ethical Boundaries)

* [ ] **Etika Akademik:** Tidak memuat instruksi pengerjaan tugas otomatis/joki, melainkan murni alat bantu manajemen tugas (*task management*).
* [ ] **Privasi Data:** Pada contoh tangkapan layar/demo, pastikan tidak ada data pribadi (seperti NIM, nama dosen asli, nomor HP, atau dokumen rahasia universitas). Gunakan data *dummy* (contoh: "Tugas Review Jurnal - Matkul Metopen").
* [ ] **Klarifikasi Output:** Hasil HTML yang ditampilkan pada visual adalah hasil nyata dari prompt Gemini yang telah diverifikasi kelayakannya di browser lokal.
* [ ] **Keterbacaan:** Ukuran font pada slide 3 (Prompt) dan slide 5 (Tutorial simpan) berukuran minimal 16-18 pt (skala mobile) agar terbaca jelas tanpa perlu diperbesar.
* [ ] **Identitas Kampanye:** Tag wajib `@REFO Indonesia` dan tagar `#GeminiAcademy #GeminiAcademyUB` sudah tertera di caption.

### Saran Pengembangan (Opsional)
*Bagian ini adalah pertimbangan tambahan yang tidak mengubah ide dasar brief:*
1. **Pemberian Template Awal:** Anda dapat menambahkan saran di slide 4 untuk meminta Gemini menambahkan palet warna khas fakultas (misal: aksen oranye FILKOM, biru FIA, atau hijau FP) agar terasa lebih personal bagi mahasiswa UB.
2. **Format Distribusi Alternatif:** Jika banyak audiens kesulitan menyalin kode dari gambar, siapkan tautan ringkas (misal: Bitly / Google Docs publik) di bio profil yang berisi file teks mentah HTML untuk diunduh langsung.
